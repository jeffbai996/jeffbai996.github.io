Home Backup

Home Backup is a private tool that stores encrypted backups of its owner's home server in the owner's own Google Drive. It is not offered to the public and has no other users.

Privacy policy

  • The tool uses the Google Drive drive.file permission. It can see and change only the files it created, and nothing else in the Drive.
  • Backups are encrypted on the owner's server before upload. Google stores only encrypted data.
  • No data from the Google account is collected, sold, shared with third parties or used for advertising.
  • Access can be withdrawn at any time from the Google Account's third-party access settings.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Terms of service
